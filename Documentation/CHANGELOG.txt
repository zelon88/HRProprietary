APPLICATION INFORMATION ...
The HRProprietary Engine provides a coherent application environment. 
It is bundled with an application rather than installed beside one.

FILE INFORMATION ...
v3.9.3.
This plain text file is the contract between an application and the Engine it bundles.

HARDWARE REQUIREMENTS ...
This application requires at least a Raspberry Pi Model B+ or greater.
This application will run on just about any x86 or x64 computer.

DEPENDENCY REQUIREMENTS ...
The Engine requires PHP. Everything else it uses, it locates at runtime and reports when it cannot find.

COMMIT 9/8/2026
v3.9.3 - Absorb Core Manager & the Cores. The Engine owns the environment.

-v3.9.3.
-Absorb coreManager.php into the engine. Delete it.
  -Four manager roles move to Resources/Engine/Managers, one file each.
  -Everything shared moves to the engine. Sockets, budgets, worker registry.
-Sandbox the Stream pipeline. Every dependency command is now sandboxed.
  -bwrap is PID 1 in its namespace, so its identifier is the right handle after all.
-Never give a tool a resolver. Pin the address instead.
  -Harden the SSRF address filter. Refuse carrier NAT, multicast, IPv4-in-IPv6.
  -curl is pinned with --resolve. FFMPEG is pinned with a hosts file.
-Split Model, Image, SCAD & Drawing config arrays into input and output.
  -SCAD was using array position to mean direction.
  -Image was offering ten formats it cannot read.
-Add five model output formats. Skip u3d, its converter is not bundled.
-Replace su with a fork that drops privilege & cannot climb back.
-Move socket directory ownership to -fp. The listener needs no privilege now.
-Give dependency probes a disposable environment & directory. No more stray .cache.
-Grow the linters to 18 checks. Negative test every one.
  -args caught two stale cleanFiles() calls that reported failure on a good conversion.
  -return catches a purge that empties what it was asked to store.
-Fix redeclare(). It was purging the value it was asked to store.
  -Broke every settings link in convertGui2 & emptied Pipeline Core's format arrays.
-Add test tools for the address filter, redeclare & the SCAD sanitizer.
  -Build tools in php are cli only & say so in the filename.
-Prove the hostname where it lands, not where it came from. /etc/hosts is line based.
-Network policy values are locals again. They were lowercase & declared global.
-Print the dependency verdict once. The component that owns the table owns the summary.
-Resolve the Engine contract. It named six application functions & now names none.
  -It checks Bubblewrap & calls one provider the application declares in engineConfig.
-Add the Environment Manager. Root, no socket, wakes on a timer & exits.
  -Watches by default. Repair is a setting & calls the same function -fp calls.
  -Not dispatchable. The listener is www-data & this refuses to be anything but root.
-Fix --kill-all-workers. It called a function with no argument & died every time.
-Delete the Wide interface. It was Original with one number changed.
  -Interface width is now --GUI Maximum Width--, fluid between the device & that ceiling.
-Add a playlist source URL field. An uploaded playlist has no address to resolve against.
-Add downloading a file from a URL. Off by default. This server has no authentication.
  -Every fetch takes the same path a playlist URL takes. Pinned, no redirects, no resolver.
-Upgrade the bundled Dropzone to 6.2.0. autoDiscover is gone, so the instance is explicit.
-The dropdown arrow follows the reading direction. The language pack decides.
-The file list panel takes a colour from the scheme instead of a hardcoded cream.
-The dropzone scrolls instead of pushing its previews over the footer.
-Fix 92 language pack labels missing an opening quote.
-Add --Logo URL--. The logo returns to a clean page carrying language, colour & interface.
  -Session tokens are never put in the link. A session belongs to the browser holding it.
-The Default file list card takes a colour from the scheme. Blue keeps white on purpose.
-List features that are installed & switched off in -v. A gated feature is invisible.
-PyMeshLab installs with pip. 2025.07 ships native arm64 wheels, so the x86 limit is gone.
  -The pipeline tries an installed copy first & falls back to a bundled one.
-Add --Version Source-- to the manifest. An entry may name a command listing what is
 AVAILABLE, & the Engine picks the highest version inside the declared window at install
 time rather than the build command naming one forever.
-Python builds from Documentation/Build, like FFMPEG & ImageMagick already did. It was the
 only source dependency carrying eight hundred characters of shell inside the manifest.
-Add --Maximum Version-- to the dependency manifest. Every entry declared a floor & none
 declared a ceiling, so a dependency past what this application supports reported ok &
 then failed at the point of use.
-Python updates within the 3.14 line & refuses to leave it. 3.14.0 was hardcoded, so no
 security patch could ever arrive, & fetching the newest would eventually break every
 compiled module by landing on 3.15.
-Name pip as a dependency. A tool that installs other tools should be auditable.
  -Verified against python3.14, not python3. They are frequently different pips.
-Know what machine this is. detectHostArchitecture in the Engine, reported by -v.
  -A manifest entry may name the architectures it supports, or override fields per one.
  -RAR points at the arm build on arm. The Debian package is x86 only.
  -PyMeshLab reports unsupported on arm rather than failing with an unreadable ImportError.
  -Syslinux is x86 only. isohybrid has nothing to do on arm & no package provides it.
  -A source build says it takes an hour on arm, so nobody kills one that is working.
  -numpy asks pip for a wheel first. On arm there often is not one & it compiles.
  -Say WHY a resource scope failed. Lingering is fixable. A kernel with no cgroup
   delegation is not, & many NAS kernels ship that way.
-Both scanner pipelines were never enumerated. They declared $PipelineFormats, which
 nothing reads, & the Pipeline Core refuses a pipeline declaring no formats, which a
 scanner does on purpose. Pinned, installed, valid & invisible.
-Virus scanning becomes pipelines. scanner is a third pipeline kind.
  -A scanner is chosen by NAME, not by extension. Every scanner claims every file.
  -A scanner reports & never deletes. What happens to an infected file is the caller's.
  -ScanCore & ClamAV ship as pipelines. --Default Virus Scanner-- picks one.
-Correct 81 file locations in ERROR_DESCRIPTIONS.txt against where each number is actually
 raised. The messages were right; the files had moved out from under them.

  ---config --repair may now run against an incomplete config. It is what fixes one.

 defaults & the application drops Contract/app-engine-config.php beside it, loaded last.
  -engineConfig.php is now the Engine's & is replaced with it. The override survives.

 visible in the tree now rather than described in a document.
-Name the environment file environmentCore.php, matching the other Cores.
